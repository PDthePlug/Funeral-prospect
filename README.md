# PD Connect Funeral Prospect Lab

Ten independent, noindex funeral-service redesign concepts created for prospect outreach.

## Prospect routes
- /rabsons-unity/
- /magezas/
- /mandoza/
- /mandys/
- /missing-angels/
- /dichaba-kopano/
- /menzokuhle/
- /songomnyama/
- /pegasus/
- /bigway/

The concepts use public business/contact information conservatively and intentionally avoid inventing funeral-plan prices, FSP numbers, underwriters, waiting periods or approved policy wording. Public mobile numbers not explicitly published as WhatsApp are labelled for verification before outreach.
